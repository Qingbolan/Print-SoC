# 未提交功能实施与验收记录

本记录用于持续核对这次“全部实现”的工作，不把编译成功等同于产品验收。
日期：2026-11-16。

## 已落地

- 文档导入使用 preparing / ready / failed 判别联合；未准备好或失败的文件不能提交。后端创建作业时再次验证 PDF、页码、份数和队列。
- PDF 本身也复制到内容寻址的持久缓存，避免预览后源文件被移动或改写；缓存损坏可重建，并发导入以原子发布避免覆盖读取中的文件。
- Booklet 实际生成两列排版 PDF；按由外至内的页序排版，补齐四页一张纸的空白，支持页码选择；预览使用对应页序。默认横向、短边翻转，保持用户随后明确选择的装订边。
- 删除未使用且只复制全文的 extract_page_range 占位实现。
- 打印生命周期集中在 job_lifecycle；重启时将明确尚未提交的准备阶段恢复为可重试失败，将可能已提交的任务恢复为结果不确定，不自动重打。
- 每次提交保存不含密码的账号身份和独立 attempt UUID。SSH 上传、提交和查询在持有会话锁时核对账号，防止切换账号后继续对错误服务器操作。
- 远端提交目录采用原子 mkdir 作为一次性准入，保存退出码和原始 lpr 回执。相同 attempt 重复执行只读取回执；不完整记录始终保持不确定。
- 后台读取回执，按精确队列 ID 或账号加独立文件名关联任务。空队列不能证明无回执的任务未提交。
- 无法自动确认的任务提供人工核对队列和纸张后关闭记录的入口；不会自动发送另一份。
- 多份打印使用一个带 copies 的队列任务；同一次前端动作有同步互斥，批量失败保留原始“不确定提交”原因。
- 本地转换进程统一由 process_service 管理，限制等待时间和诊断读取；本地排版支持协作取消。Unix 测试验证超时/取消后子进程也不再运行。
- 窗口缩放由单一控制器串行提交原生几何变化，新手势等待旧写入完成再读取原点，防止快速连续拖动使用过期几何。
- 打印机目录以当前连接身份为准，不再使用旧保存账号的服务器类型。
- 系统密码替换先写新条目再清理旧条目；清理失败时恢复新条目原值。退出先断开连接，密码库清理失败时保留禁用自动复用的身份以便重试删除。
