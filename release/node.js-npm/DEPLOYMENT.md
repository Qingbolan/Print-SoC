# Node launcher maintenance

This source package is private and is no longer published to npm.
Install supported releases from [PyPI](https://pypi.org/project/print-at-soc/)
or [GitHub Releases](https://github.com/Qingbolan/Print-SoC/releases).

The launcher and its regression tests remain for existing integrations. Run
`npm test` in this directory. See [VERSIONING.md](../../VERSIONING.md) for
the coordinated desktop and Python release workflow.
